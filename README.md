A tiny stack virtual machine for the make.fun bounty
tiny-stack-vm-01-run-20261122 ("Build a tiny stack virtual machine").

`main.ts` runs one bytecode program of make.fun's tiny stack ISA and
answers with exactly the bytes it writes and the exit code it ends with.
See `BUILD_REPORT.md` for the design and the practice results.
